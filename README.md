# 💻 Laptop Price Predictor

## 📌 Overview

The **Laptop Price Predictor** is a Machine Learning regression project designed to predict the price of a laptop based on its technical specifications.

The project demonstrates an end-to-end Data Science workflow, including data preprocessing, exploratory data analysis, feature engineering, model training, evaluation, and prediction.

## 🎯 Objective

The main objective is to develop a machine learning model capable of estimating laptop prices from features such as:

* Brand
* Processor
* RAM
* Storage
* GPU
* Screen size
* Screen resolution
* Operating system
* Weight
* Other laptop specifications

Since laptop price is a continuous numerical variable, this is treated as a **supervised learning regression problem**.

## 🤖 Machine Learning

Several regression algorithms can be explored and compared to determine which provides the best predictive performance.

Model performance can be evaluated using metrics such as:

* **R² Score**
* **Mean Absolute Error (MAE)**
* **Mean Squared Error (MSE)**
* **Root Mean Squared Error (RMSE)**

The best-performing model is selected for making predictions on new laptop specifications.
